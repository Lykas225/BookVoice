# BookVoice

Читалка с озвучкой ИИ-голосом. Без рекламы и регистрации.

- Открывает: EPUB, FB2 (и FB2.ZIP), DOCX, ODT, PDF (с текстовым слоем), RTF, HTML, Markdown, TXT
  (в том числе в кодировке windows-1251).
- Файлы можно добавлять из приложения, через «Открыть в…» / «Поделиться» или вставить текст.
- Бесплатные книги: каталоги OPDS (по умолчанию Project Gutenberg).
- Озвучка: офлайн (Sherpa-ONNX + Piper) или онлайн (Yandex SpeechKit).
- Запоминает место чтения в каждой книге.
- Читает в фоне и при выключенном экране: уведомление с кнопками, мини-плеер, пауза при звонке и отключении наушников.

Сборка: см. .github/workflows/build.yml (GitHub Actions собирает APK и кладёт в Releases -> latest-apk).
